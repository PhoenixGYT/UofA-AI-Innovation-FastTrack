# OnboardAI

OnboardAI is a full-stack Node.js web app for onboarding support hires with source-grounded answers.

## Features
- Email/password `sign up` and `sign in`
- Split accounts by role: `HR` and `Employee`
- Authenticated onboarding Q&A endpoint (`/api/ask`)
- Source citations for grounded responses with links to original passages
- Escalation behavior for HR decisions (approval, salary, benefits)
- Refusal to fabricate answers for missing information
- "Ask for confirmation of options" behavior for tool-choice questions
- HR can define which source guides each employee can access

## Tech stack
- Express
- MongoDB (`mongoose`)
- JWT auth
- Vanilla JS frontend

## Local setup
1. Install dependencies:
   - `npm install`
2. Create environment file:
   - `cp .env.example .env`
   - set `JWT_SECRET` to a secure value
   - set `MONGODB_URI` (local MongoDB or MongoDB Atlas)
3. Run:
   - `npm start`
4. Open:
   - `http://localhost:3000`

## Deploy on Render
1. Push this project to a Git repo.
2. In Render, create a **Web Service** from the repo.
3. Render can auto-detect `render.yaml`.
4. Ensure environment variable `JWT_SECRET` is set (auto-generated by `render.yaml`).
5. Set `MONGODB_URI` in Render environment variables (Atlas or other Mongo host).
6. Deploy.

The app uses MongoDB mode only.
